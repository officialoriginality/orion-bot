Orion Documentation

Complete list of Orion moderation commands and what they do.

← Back to Orion Privacy Policy Terms of Service
Ping
?ping

Checks if the bot is online.

Hi
?hi

Orion says hi to you.

Kick
?kick @member [reason]

Kicks a member from the server.

Ban
?ban @member [reason]

Bans a member from the server.

Softban
?softban @member [days] [reason]

Bans then immediately unbans a member to purge their recent messages.

Unban
?unban user_id

Unbans a user by their ID.

Mute
?mute @member [reason]

Mutes a member using a persistent Muted role.

Unmute
?unmute @member

Removes the Muted role from a member.

Timeout
?timeout @member minutes [reason]

Times out a member for a number of minutes.

Untimeout
?untimeout @member

Removes an active timeout from a member.

Warn
?warn @member [reason]

Warns a member and logs it. Auto-timeouts/kicks at set thresholds.

Warnings
?warnings @member

Shows all warnings a member has.

Clear Warnings
?clearwarnings @member

Clears all warnings for a member.

Mod Logs
?modlogs @member

Shows a member's full moderation history.

Case
?case id

Shows details for a specific moderation case.

Delete Case
?delcase id

Deletes a moderation case.

Note
?note @member text

Adds a private mod note to a member.

Notes
?notes @member

Shows a member's mod notes.

Clear
?clear amount [@member] [keyword]

Deletes recent messages, optionally filtered by member or keyword.

Role
?role @member partial role name

Toggles a role on or off for a member. You can type part of the role's name.

Lock
?lock [channel|all]

Locks a channel, or every channel in the current category if you say "all".

Unlock
?unlock [channel|all]

Unlocks a channel, or every channel in the current category if you say "all".

Lock Status
?lockstatus

Shows which channels are currently locked.

Lockdown
?lockdown

Locks every text channel in the server.

Unlockdown
?unlockdown

Unlocks every text channel in the server.

Slowmode
?slowmode on|off

Turns 5 second slowmode on or off in the current channel.

Filter Invites
?filterinvites on|off

Toggles auto-deletion of Discord invite links.

Block Domain
?blockdomain add|remove|list [domain]

Manages a list of blocked domains that get auto-deleted.

Raid Mode
?raidmode on|off

Toggles automatic server lockdown when a join-raid is detected.

Set Warn Threshold
?setwarnthreshold timeout|kick count

Sets how many warnings trigger an automatic timeout or kick.

Commands / Cmds
?commands

DMs you this list of commands.
