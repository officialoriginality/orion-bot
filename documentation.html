Orion Documentation

Commands and features

General Commands

  • ?ping — Checks if the bot is online.
  • ?hi — Orion says hi to you.
  • ?help — Displays the available commands.

Moderation Commands

  • ?kick @member [reason] — Kicks a member from the server.
  • ?ban @member [reason] — Bans a member from the server.
  • ?timeout @member [duration] [reason] — Temporarily times out a member.
  • ?warn @member [reason] — Issues a warning to a member.
  • ?warnings @member — Displays a member's warning history.
  • ?clearwarnings @member — Clears a member's warning history.

Server Management

  • ?lock — Locks the current channel.
  • ?unlock — Unlocks the current channel.
  • ?slowmode [seconds] — Sets the slowmode delay for the current channel.
  • ?role @member @role — Adds or removes a role from a member.
