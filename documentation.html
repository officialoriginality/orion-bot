Commands and features

General Commands

  • ?ping — Checks if the bot is online.
  • ?hi — Orion says hi to you.
  • ?help — Displays the available commands.

Moderation Commands

  • ?kick @member [reason] — Kicks a member from the server.
  • ?ban @member [reason] — Bans a member from the server.
  • ?timeout @member [duration] [reason] — Temporarily times out a member.
  • ?warn @member [reason] — Issues a warning to a member.
  • ?warnings @member — Displays a member's warning history.
  • ?clearwarnings @member — Clears a member's warning history.

Server Management

  • ?lock — Locks the current channel.
  • ?unlock — Unlocks the current channel.
  • ?slowmode [seconds] — Enables or changes slowmode in the current channel.
  • ?role @member [role] — Manages a member's server role.

Command Usage

Commands are entered using Orion's configured command prefix. Arguments shown in square brackets are optional unless otherwise specified.

Example: ?warn @member Spamming in chat

Permissions

Moderation commands require the appropriate Discord permissions. Orion will only perform actions that the bot itself has permission to perform and that the command author is authorized to request.
