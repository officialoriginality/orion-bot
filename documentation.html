Commands and moderation tools available in Orion.

← Back to Orion Documentation Privacy Policy Terms of Service

Below is a list of commands currently available in Orion. Commands use the ? prefix.

General

  • ?ping Checks if the bot is online.
  • ?hi Orion says hi to you.

Moderation

  • ?kick @member [reason] Kicks a member from the server.
  • ?ban @member [reason] Bans a member from the server.
  • ?timeout @member [duration] [reason] Temporarily prevents a member from communicating in the server.
  • ?warn @member [reason] Gives a member a warning and stores the warning in their history.
  • ?warnings @member Displays the warning history for a member.
  • ?clearwarnings @member Clears the stored warnings for a member.

Server Management

  • ?lock Locks the current channel so regular members cannot send messages.
  • ?unlock Unlocks the current channel.
  • ?slowmode [seconds] Sets slowmode for the current channel.

Roles

  • ?addrole @member [role] Adds a specified role to a member.
  • ?removerole @member [role] Removes a specified role from a member.
Note: Some commands require specific Discord permissions. Orion will only perform moderation actions that its bot account has permission to perform.
